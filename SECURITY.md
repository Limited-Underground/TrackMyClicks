# Security reporting

TrackMyClicks is experimental; no supported public binary release is established yet.

Use GitHub **Security > Advisories > Report a vulnerability** in this repository for a private report. See the [private reporting page](https://github.com/Limited-Underground/TrackMyClicks/security/advisories/new). If that control is unavailable, open a public issue requesting a private reporting route without disclosing the vulnerability, personal data or exploit details.

Include the affected version/commit, impact and a minimal synthetic reproduction. Do not send real activity databases, credentials, identifying paths, typed content or private logs. Coordinate disclosure with the maintainer after a fix. No guaranteed response time or automatic disclosure deadline is asserted.
